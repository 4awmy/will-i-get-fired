# Arab Academy for Science, Technology & Maritime Transport
## College of Computing and Information Technology

# Project Description

Each team of 3 students must choose a real-world problem and build a complete Data Science / Artificial Intelligence project using Python.

The project should not be a simple implementation of one model only.

Students are required to apply the full Data Science workflow, try more than one algorithm, compare the results, improve the model, and clearly explain every step they performed.

The main goal of this project is to help students gain practical experience in solving real problems using data, machine learning algorithms, evaluation techniques, and result interpretation.

---

# Project Objective

By the end of this project, students should be able to:

- Understand a real-world problem.
- Search for and select a suitable dataset.
- Analyze and clean real data.
- Apply different preprocessing techniques.
- Train and compare multiple Machine Learning algorithms.
- Improve model performance.
- Evaluate results using suitable metrics.
- Explain what they changed and why.
- Present the final solution clearly.

---

# Required Project Work

## 1. Problem Understanding

Students must explain:

- What is the problem?
- Why is this problem important?
- Who can benefit from this project?
- What is the input of the system?
- What is the expected output?
- What type of problem is it?

Possible problem types:

- Classification
- Regression
- Clustering
- Recommendation System
- NLP
- Computer Vision

---

## 2. Dataset Selection

Each team must choose a real dataset from a trusted source such as:

- Kaggle
- UCI Machine Learning Repository
- Public GitHub datasets
- Google Dataset Search
- Official public datasets

The dataset must be suitable for applying Machine Learning.

Students must include:

- Dataset source link
- Number of rows
- Number of columns
- Feature names
- Target column
- Data types
- Dataset description

---

## 3. Data Understanding and Exploration

Students must perform Exploratory Data Analysis (EDA).

### Required:

- Display first rows of the dataset
- Show dataset shape
- Show data types
- Check missing values
- Check duplicate values
- Show basic statistics
- Analyze the target column
- Explain important columns
- Identify problems in the dataset

---

## 4. Data Visualization

Each team must include at least 6 visualizations.

### Important:

Each chart must include a short explanation answering:

- What does this chart show?
- What did you learn from it?
- How does it help in understanding the data?

---

## 5. Data Preprocessing

Students must apply suitable preprocessing techniques according to the dataset.

### Possible preprocessing steps:

- Handling missing values
- Removing duplicates
- Encoding categorical columns
- Feature scaling
- Handling outliers
- Feature selection
- Train-test split
- Balancing imbalanced data if needed
- Text cleaning for NLP projects
- Image resizing/normalization for image projects

Students must explain:

- What preprocessing steps were applied?
- Why did they apply these steps?
- What changed in the dataset after preprocessing?

---

## 6. Machine Learning / AI Models

Each team must apply at least 3 different algorithms.

The algorithms must be suitable for the selected problem.

---

## 7. Model Comparison

Students must compare all applied models.

The comparison should include:

- Model name
- Accuracy or suitable metric
- Training time (optional)
- Advantages
- Disadvantages
- Best model
- Reason for choosing the best model

---

## 8. Model Improvement

This part is very important.

Students must not stop after the first result.

They must try to improve the model by changing something and explaining the effect.

### Examples of improvements:

- Changing preprocessing method
- Removing unnecessary columns
- Adding feature scaling
- Handling outliers
- Trying different algorithms
- Changing train-test split
- Using feature selection
- Handling imbalanced data
- Hyperparameter tuning
- Using cross-validation

Students must explain:

- What was the first result?
- What did they change?
- Why did they change it?
- Did the result improve or not?
- What is the final best result?

---

## 9. Model Evaluation

Students must use suitable evaluation metrics.

### Classification Metrics

- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix

### Regression Metrics

- MAE
- MSE
- RMSE
- R² Score

### Clustering Metrics

- Elbow Method
- Silhouette Score
- Cluster visualization

Students must explain the results, not only display numbers.

---

## 10. Prediction / Demo

Each team must show a simple working demo.

The demo can be:

- A function inside the notebook
- A user input cell
- A simple Streamlit app
- A screenshot showing prediction result

The demo should show how the final model can be used on new data.

---

## 11. Final Discussion

Students must include a discussion section answering:

- Which model gave the best result?
- Why did this model perform better?
- What problems did you face?
- How did you solve them?
- What changes improved the result?
- What are the limitations of the project?
- How can the project be improved in the future?

# Important Rules

- Each team must consist of 3 students only.
- The project must be more advanced than Assignment 1.
- Each team must apply at least 3 algorithms.
- Students must compare the algorithms.
- Students must explain what they changed and how it affected the result.
- Copying from another team is not allowed.
- The notebook must run without errors.
- Both students must understand and present the project.
- Any dataset, code, article, or AI tool used must be mentioned in the references.
- Projects with only copied code and no explanation will lose marks.
